# Portfolio — Putera Nami Shiddieqy

Website portofolio personal **CodeNami by Putera Nami** yang menampilkan karya pilihan di bidang product engineering, full-stack development, artificial intelligence, data, mobile, dan infrastructure.

## Fitur

- Desain responsif untuk desktop, tablet, dan mobile.
- Tema terang/gelap dengan preferensi tersimpan di browser.
- Navigasi aktif dan animasi masuk berbasis `IntersectionObserver`.
- Filter proyek berdasarkan kategori.
- Section khusus personal brand CodeNami dan arsip proyek dari CV.
- Data portofolio dipisahkan dari komponen agar mudah diperbarui.
- Tombol salin email dengan fallback ke aplikasi email.
- Aksesibilitas dasar: semantic section, skip link, focus state, ARIA, dan reduced motion.
- Vercel Web Analytics.

## Stack

- React 19
- Vite 7
- Lucide React
- Vanilla CSS
- Vercel Analytics

## Menjalankan secara lokal
